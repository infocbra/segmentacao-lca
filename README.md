# Projeto sobre Segmentação do LCA

Projeto voltado à segmentação automática do Ligamento Cruzado Anterior (LCA) em imagens de ressonância magnética do joelho utilizando técnicas de aprendizado profundo e redes neurais convolucionais.

## Objetivo

Desenvolver e avaliar modelos de segmentação baseados na arquitetura U-Net, considerando diferentes estratégias de treinamento e utilização de pesos pré-treinados.

## Estrutura do projeto

- metadata/: metadados e divisão dos dados.
- notebooks/: notebooks de pré-processamento e experimentação.
- src/: implementação dos modelos e rotinas de treinamento.
- resultados/: armazenamento dos resultados dos experimentos.

## Tecnologias

- Python
- PyTorch
- U-Net
- Google Colab
